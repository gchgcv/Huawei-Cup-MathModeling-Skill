# Argument Deepening

Normative rules: `DEPTH-001`–`DEPTH-005`, `CLAIM-001`, `CLAIM-002`.

## Evidence-First Deepening

对薄弱段落依次检查：

1. 缺少模型关系：补充已有变量、目标、约束或参数依据；
2. 缺少定量证据：引用已有结果、区间、差值或排序；
3. 缺少解释：连接题目条件、模型结构和结果现象；
4. 缺少题意意义：说明结果回答了哪个决策或子问题；
5. 缺少边界：只加入由现有证据确定的范围。

如果所需证据不存在，输出证据缺口，不补写数字、实验、检验或机理。增加术语、篇幅、公式数量或免责声明不等于增加深度。
