# Result Discussion Writing

Normative rules: `DEPTH-002`, `DEPTH-003`, `DEPTH-005`, `FIG-004`, `FIG-005`, `CLAIM-006`.

## Core Result Pattern

1. 指出最重要的现象或差异；
2. 给出可追溯的数值、区间、排序或图表位置；
3. 用模型结构、约束或题目条件解释原因；
4. 说明该结果如何回答当前子问题；
5. 只有在影响解释时加入异常、权衡和适用边界。

## Special Cases

- 模型对比：说明基准、指标和差异幅度；
- 敏感性：只说明实际测试的参数、范围和排序变化；
- 验证结果：说明误差、残差、可行性或理论条件；
- 弱结果：按目标差异和约束解释，不隐藏也不夸大为整体失败。

caption 与正文不得重复堆叠同一句结论。图内数据、正文数字和受保护结果必须一致。
