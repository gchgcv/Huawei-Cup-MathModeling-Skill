# Anti-Defensive Transformation

Normative rules: `ADW-001`–`ADW-006`, `CLAIM-001`, `CLAIM-006`.

## Sentence Classification

先把限定句标为以下一种，再决定处理方式：

1. 无信息免责：删除；
2. 必要适用范围：改成正面范围；
3. 真实方法局限：保留并放到影响解释的位置；
4. 有用概念对比：保留其定义作用；
5. 证据强度限定：写明不确定性来源；
6. 冗余澄清：删除或与首次说明合并。

## Transformation Order

```text
识别核心主张
→ 定位支持证据
→ 分类限定句
→ 删除无信息免责
→ 将负面范围改为正面范围
→ 将模糊犹豫改为具体来源
→ 把必要边界放到唯一合适位置
→ 核对主张没有被扩大
```

## Paragraph-final Negative Scope

同一段或相邻段落若反复以“未通过、未包含、未覆盖、未验证、未达到”收尾，
先保留其事实含义，再改成正面证据边界：

```text
跨评委组的稳定增量判定仍未通过
→ 更换评委组后，不同模型给出的增量方向仍不一致。该结果反映的是当前模型和评委组条件下的预测变化

验证协议未包含独立外部测试
→ 当前结果反映模型在内部交叉验证下的表现，外部泛化能力还需在独立样本上进一步检验
```

转换后的句子必须回答“现有证据支持什么、适用于哪里”，不能只把“未”替换成
另一个否定词。若否定本身是核心结果，保留该结果，并在下一句给出其条件和决策含义。
正面改写也不能把现象、原因、条件和范围重新压缩成一句规则化长句。一个句子优先
承担一个主要判断：先写观察结果，再用下一句说明解释范围或判定条件。

不得为了让语气更自信而删除核心负面证据、真实样本边界或方法失效条件。
