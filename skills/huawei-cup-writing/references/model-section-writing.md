# Model Section Writing

Normative rules: `DEPTH-001`, `STRUCT-002`, `STRUCT-003`, `TERM-002`, `NUM-001`–`NUM-004`.

## Input Boundary

只使用已经给出的模型、公式、代码映射、参数和求解证据。本文件不负责选择或升级模型。

## Construction Order

1. 说明题目特征为什么需要当前模型关系；
2. 定义变量、集合、参数、单位和来源；
3. 解释目标函数或状态关系如何对应题目目标；
4. 逐类说明关键约束的现实含义；
5. 写清已实际采用的求解方法和必要设置；
6. 说明输出如何回答本问并进入后续结果；
7. 只引用已经完成的验证、对比或敏感性证据。

空间位置、方向、角度和几何关系不能只放入符号表；已有示意图时应与图中标注和正文说明保持同一符号语义。
