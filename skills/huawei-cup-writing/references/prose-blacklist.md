# Academic Prose Rewrite Corpus

本文件是 Writing 的改写语料库，不是作者来源识别器，也不是全局禁词表。它把高频的审核腔、机械标签链和空泛评价整理为“触发条件—作用域—推荐改写”，供最终论文正文进行人工语境改写。

## Scope contract

| 语境 | 处理方式 |
|---|---|
| `writing_final_prose`：摘要、连续正文、图后分析和结论 | 触发后原则上改写；保留其中承载的负面结果、局限和适用范围 |
| `review_report`：审核意见、finding、审计记录 | 可以直接使用“不能据此”“证据不足”等诊断语言；不应原样移植到论文正文 |
| `figure_label`、流程图节点、表格阶段名、算法伪代码 | 标签链和必要的短语可以保留；不作为连续正文的句式模板 |
| 引用原文、正式术语、题目原始表述 | 按引用和术语规则处理，不因命中词面而擅自改义 |

本库只产生改写触发，不自动替换文本。触发后先判断句子承担的是结果、证据、范围、局限还是接口说明，再选择对应的正向表达。任何改写都必须继续保护数字、公式、模型名称、负面证据、验证层级和主张边界。

## HARD_REWRITE：最终正文中的高风险审核腔

下列表达在审核报告中有明确用途，但在最终论文正文中通常会把作者语气变成“自我审查”。出现时，优先把禁止性判断改写为“当前结果表明什么、适用于什么条件、还需要什么验证”。

| 高风险表达 | 正向改写方向 |
|---|---|
| 需要指出的是；值得指出的是；必须说明的是 | 直接写当前结果、条件或结论；只有该前置条件确实决定后文解释时才保留引导 |
| 不能据此证明/说明/认为/宣称…… | 先写当前结果支持的对象和范围，再写更宽范围仍需何种验证 |
| 现有证据不足以支持……；现有结果仅支持…… | 写“当前对照实验表明……”“结果适用于……”，并将证据强度放在具体条件中 |
| 尚不能说明……；尚不足以证明…… | 写已观察到的变化及其验证层级，不把未完成的检验写成已完成 |
| 不能外推为……；不能扩展为……；不能简单认为…… | 写迁移时所需的重新参数化、场景验证或数据条件 |
| 不应将……解释为…… | 直接区分观察结果与解释范围，例如“该结果反映……，不涉及……” |
| 支持将……表述为…… | 直接陈述论文采用的设计、对照证据和当前范围，不讨论“如何命名” |

### Preferred rewrites

| 审核式写法 | 论文正文写法 |
|---|---|
| 不能据此证明模型具有良好泛化能力。 | 当前结果反映模型在本数据集及当前测试划分下的预测表现，其跨数据集表现仍需在独立样本上验证。 |
| 现有证据不足以支持算法显著优于基线。 | 当前对照实验中该方法取得了更低误差，差异的统计稳定性仍需进一步检验。 |
| 不能认为模型适用于所有城市。 | 模型迁移至其他城市时，需要依据当地路网、容量和需求重新参数化，并在对应场景下进行验证。 |
| 不能据此说明 XGBoost 在所有场景下更优。 | 在本数据集及当前测试划分下，XGBoost 取得了三种模型中的较低预测误差。 |
| 现有结果仅支持将其表述为方法改进。 | 该调整局限于变异环节，并在当前对照实验中取得了更低的平均综合目标值，因此构成对标准 NSGA-II 变异机制的针对性改进。 |
| 需要指出的是，本次比较未进行外部验证。 | 当前结果来自内部测试划分；模型在外部数据上的表现仍需单独验证。 |

改写时不得为了消除审核腔而删掉“未进行显著性检验”“峰值样本数量有限”“外部数据未验证”等会改变读者判断的事实。必要时保留事实，再用下一句给出其对适用范围的影响。

## PATTERN_REWRITE：机械标签链

连续学术正文中，下面的结构属于高风险模式：

```text
构建/建立/形成/搭建“ A—B—C ”的研究框架、模型链、技术路线、分析框架、完整闭环、模型体系或一体化流程
按照“ A—B—C ”的思路……
围绕“ A—B—C ”展开……
```

问题不在破折号本身，而在于用三个名词标签代替真实的因果、递进、输入输出或任务关系。改写时应说明前一阶段的输出如何进入后一阶段，以及每一阶段回答什么问题。

| 机械标签链 | 推荐改写 |
|---|---|
| 构建“候选点评价—布局优化—扰动分析”的研究框架。 | 候选点评价结果用于缩小后续选址范围；在此基础上确定储备点布局，再以所得方案为对象分析道路扰动下的系统响应。 |
| 形成“评价—优化—验证”的完整闭环。 | 评价结果作为优化模型的输入，优化所得方案进一步进入验证环节，三个阶段通过实际输入输出关系相互衔接。 |
| 建立“数据—模型—决策”的一体化流程。 | 将给定数据转换为模型参数，通过求解得到方案，并依据方案指标完成决策比较。 |
| 围绕“识别—预测—优化”展开研究。 | 先识别影响目标的因素，再利用识别结果建立预测关系，最后将预测结果用于优化决策。 |

### Context exceptions

以下位置可以保留标签链，但不得把它当作正文论证的替代品：

- 流程图节点、架构图节点和图内简短标签；
- 图题、表题或表格中的阶段名称；
- 算法伪代码、程序日志和明确要求紧凑表示的流程摘要；
- 对题目原文或已有正式名称的直接引用。

即使标签链出现在图题或表格中，图表下方的正文仍应解释实际的输入、输出和依赖关系。

## SOFT_TRIGGER：需结合频率和证据判断

下列表达并非绝对错误，但在一篇论文中重复出现、或句中没有紧邻证据时，应优先改写：

```text
从结果可以看出；由图可知；可以发现；由此可见；综上可见；
由此可以看出；由上述分析可知；综合来看；综上所述；
充分说明；有效验证了；具有较好的；具有较强的；具有重要意义；
具有一定的参考价值；为后续研究提供了可靠基础；效果很好；性能优越；
明显提升；显著提升；稳定性较好；准确性较高。
```

处理顺序是：先删除无信息的路标，直接写观察结果；再把评价词替换为数值、排序、图中具体区域、约束检查或对照对象。只有正式技术含义或有直接证据支撑时才保留评价词。一次出现且承担必要的读图引导时，可以不机械删除；高频重复时应合并相邻句段。

“该结果表明”本身不是改写目标。当它紧接具体指标、图表现象或约束检查，并引出有边界的结论时，可以保留。类似地，“当前模型尚未考虑”“本次实验未覆盖”“当前分析采用”“现有验证范围包括”等句式是在陈述研究覆盖范围，不能仅因含有“未”字而删除或改成更强的结论。

### Agent meta-prose

以下句式不是硬禁词，但若只是在说明作者接下来如何组织答案，而没有传递题目关系或证据，应删去或改成直接分析：

```text
因此需要分别明确……；下文将重点分析……；为了更好地解决上述问题……；
为后续分析奠定基础……；下面分别进行讨论……；从上述分析可以发现……。
```

例如，“因此需要分别明确其数据关系和任务边界”可以直接改为“问题三虽共享部分原始数据，但在模型输入和分析目的上独立”。“按照时间顺序划分训练集和测试集”只能保留该已知方法；只有材料明确给出目的时，才补写防止数据混用、避免信息泄露等解释。

## SOFT_TRIGGER：接口审计化与工作状态泄漏

独立问题的关系说明也可能出现过度否定。单独说明“不使用某项结果”有时是必要的，但在同一段连续写“不使用、不调用、不依赖、不提供”时，正文会变成接口审计记录。优先分别写每个问题实际消费的数据、产生的输出及其用途，让独立性从正向描述中自然显现。

```text
审计化：问题三不使用问题一结果，也不调用问题二结果，不为问题二提供参数。
正文式：问题三根据门店面积、商圈客流量、运营成本和历史销量刻画长期经营类型，其聚类结果与前两问的预测和库存分配分别形成独立结论。
```

“当前尚未完成实际求解”“最终结果仍待计算”等句子适合工作日志或状态报告，不宜占据正式问题分析。若题目材料尚未提供结果，直接写“模型用于确定……”或“通过求解可得到……”，不要虚构结果，也不必把未求解状态写进论文正文。

## Chapter-specific rewrite moves

| 章节 | 优先保留的论证动作 | 常见改写方向 |
|---|---|---|
| 摘要 | 任务—方法—最有信息量的结果—必要范围 | 不把所有中间编号和重复扰动数字塞入摘要；保留最终方案及关键结果 |
| 问题分析 | 题目特征、问题接口和待求输出 | 用“评价结果作为候选集合”“所得布局用于扰动分析”说明真实承接，不写空泛模型链 |
| 模型建立 | 建模依据、公式对象、变量作用和输出 | 公式前写为什么需要该关系，公式后写变量及其在当前问题中的作用 |
| 结果分析 | 观察—定量证据—对照—解释—题意意义 | 测试集写“预测值与真实值”，训练阶段才使用“拟合”；弱结果写清权衡 |
| 特色与创新 | 实际设计、基线、具体变化、对照证据 | 直接陈述“本文在变异环节调整……”，不写“证据支持将其表述为……” |
| 结论与推广 | 当前对象、条件、验证层级和迁移要求 | 用“模型迁移时需要重新参数化并验证”替代连续的“不能适用于……” |

## Final prose isolation check

交付最终论文正文前逐句检查：

1. 句子是否直接陈述了结果、关系、条件或决策，而不是作者正在审查自己的表述？
2. “不能据此”“证据不足”“仅支持”等边界是否已转为正向适用范围，同时保留了核心负面证据？
3. 是否用“构建/形成‘A—B—C’框架”代替了实际的输入输出关系？若是，改成完整句法。
4. “较好、较强、有效、显著、稳定”等词是否有紧邻的数值、对照、检验或明确技术含义？
5. 摘要、结果和结论是否只保留对当前任务最有信息量的数字，而非机械重复全部结果表？

本检查只评价可观察的表达风险，不判断文本来源；Review 可以保留诊断性语言，Writing 最终正文需要完成语体隔离。
