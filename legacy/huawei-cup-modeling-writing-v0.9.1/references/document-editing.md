# 深层参考：论文编辑载体与模板来源

本文件只解决一个问题：agent 到论文写作、修改或交付阶段时，究竟编辑哪个源文件、使用哪个模板，以及没有模板时允许做什么。

## 1. 总原则：先确定主编辑源，再动正文；没有授权不得新建 LaTeX 源

任何涉及论文文件的任务，在实际编辑前先确定：

```text
master_source = 当前唯一主编辑源
source_format = latex | docx | markdown | other
template_source = official | user | skill_fallback | none
final_output = pdf | docx | tex | markdown | other
```

如果这些信息能从已有文件、项目结构或用户指令中确定，就直接记录，不重复询问。

不得同时把多个互相独立的文件都当作主稿。若存在 PDF 与可编辑源文件，PDF 默认是核对对象，不是主编辑源。

**LaTeX 文件创建采用显式授权规则：**除非用户明确要求“创建/新建一个 LaTeX 文件或 LaTeX 工作稿”，否则不得新建 `.tex`。用户要求“修改论文”“优化排版”“修复 LaTeX”“继续这个项目”均不构成新建授权。没有授权且找不到可编辑主源时，保持内容输出/补丁建议，不自行创建替代稿。

## 2. 主编辑源与提交格式是两件事

不要用一个优先级同时决定“编辑哪个文件”和“最终按什么格式提交”。

### 2.1 主编辑源优先级

1. 用户明确指定的当前主稿；
2. 能够生成当前 PDF 的现有可编辑源；
3. 当前项目中内容最完整且依赖关系明确的可编辑源；
4. 用户指定的新模板；
5. 当届官方模板；
6. skill 工作稿；
7. 纯内容输出。

主编辑源的目标是避免重复建稿和格式漂移。用户给出完整 `.tex/.cls/.sty` 项目时，继续在该项目中编辑；用户给出 `.docx` 主稿时，不擅自迁移到 LaTeX。

### 2.2 提交格式权威优先级

1. 当届竞赛官方论文标准文档、格式规范和模板；
2. 已经逐项核对并确认符合当届要求的用户模板；
3. skill 工作稿，仅用于编辑和排版开发，不具备提交权威性。

因此，现有 LaTeX 可以继续作为主编辑源，但最终 PDF 仍必须满足当届官方标准。若官方只提供 Word 模板，不得把自制或转换后的 LaTeX 声称为“官方 LaTeX 模板”。

样例论文只用于结构与表达参考，永远不是排版模板。

## 3. LaTeX 的默认行为

### 3.1 已有 LaTeX 项目

优先编辑现有入口文件及其依赖：

```text
main.tex / Demo.tex / paper.tex
.cls
.sty
.bib
figures/
```

先识别：

- `\documentclass`；
- 主入口文件；
- 编译引擎；
- 自定义宏与编号规则；
- 图表目录；
- 参考文献方式；
- 当前 PDF 是否由该源生成。

除非用户要求，不重写整个导言区，不随意替换 `documentclass`，不删除不理解的 `.cls/.sty`。

### 3.1.1 正文列表与模板约定

编辑竞赛论文时，列表样式必须服从当前 `.cls` 和用户指定模板，而不是由编辑者自行添加。若模板正文要求中文顺序段落，应直接写成 `（1）`、`（2）` 等文字段落；不得在正文中新增 `enumerate`、`\item` 或 `\setlist` 来模拟列表。只检查正文源码中的列表使用，不改写类文件内部宏、参考文献环境或其他模板实现所需的 `\item`。

### 3.2 用户明确要求新建 LaTeX，且没有任何模板

只有用户已经明确授权新建 LaTeX 文件时，才进入本节。不得每次临时发明一套不同的模板。统一使用模板来源：

```text
templates/latex/working-draft/main.tex
```

该模板只用于**可编译工作稿**，其身份必须记录为：

```text
template_source = skill_fallback
submission_template_verified = false
```

它不是华为杯官方模板，也不能仅因编译成功就进入 `READY_TO_SUBMIT`。

在正式提交前，必须把排版迁入或校准到当届官方标准文档，并重新做版式审核。

### 3.3 已有官方 Word 模板但用户坚持 LaTeX

可以使用用户认可的 LaTeX 模板或 skill 工作稿完成内容和排版开发，但必须明确：

- LaTeX 只是编辑源；
- 最终 PDF 需要逐项对照当届官方格式；
- 不得把转换后的 LaTeX 称为官方模板；
- 封面、摘要页、匿名信息、页边距、字号、编号等以官方文档为准。


## 3.4 LaTeX 编辑后的终稿复核

任何 LaTeX 主稿形成候选终稿后，统一转交 `references/latex-pdf-layout-audit.md` 执行编译日志与最终 PDF 版面审核。本文件只负责确定编辑源和模板策略，不重复定义 PDF 审核细则。

## 4. Word / DOCX 的默认行为

### 4.1 已有 DOCX 主稿或官方模板

直接编辑该文件或其副本，优先保留：

- 样式表；
- 节与分页；
- 页边距；
- 页眉页脚；
- 封面与摘要页；
- 图表题注；
- 公式和交叉引用。

不得为了“统一格式”把已有样式全部清空后重建。

### 4.2 用户要求 DOCX，但没有模板

只允许生成**工作稿 DOCX**。使用常规、克制的论文结构，不宣称符合当届竞赛格式。正式提交前必须迁入或对照当届官方模板。

## 5. Markdown 的位置

当用户只要求：

- 章节内容；
- 建模推导；
- 编程说明；
- 图表规划；
- 论文大纲；

且没有要求生成正式论文文件时，优先使用 Markdown 或纯文本内容，不主动生成 LaTeX/Word 文件。

Markdown 是内容载体，不是竞赛提交模板。

## 6. PDF 的位置

PDF 默认是最终输出和审核对象，不是首选编辑源。

- 有可编辑源时，修改源文件后重新生成 PDF；
- 只有 PDF 时，可做内容、图表和版式审核；
- 若必须从 PDF 重建可编辑稿，必须标记为 `RECONSTRUCTED`，不得声称完全保留原模板结构；
- 终稿应再次比较重建版与原 PDF/官方模板。

## 7. 不允许的行为

- 用户已有主稿时另建一套完全不同的模板；
- 未经用户明确授权创建 `main_fixed.tex`、`main_new.tex`、`final.tex`、`paper_revised.tex`、`submission.tex` 等平行 LaTeX 主稿；
- 把“备份”副本继续当作新的工作主源；
- 未检查项目就重写 LaTeX preamble；
- 把 skill 工作稿模板称为华为杯官方模板；
- 把上一届模板自动认定为本届模板；
- 只根据样例论文视觉效果反推并自造“官方格式”；
- 有 DOCX 官方模板时，未经说明直接转换为 LaTeX 并声称格式等价；
- 把 PDF 当作可无损编辑的源文件；
- 在模板来源不明确时把论文标成 `READY_TO_SUBMIT`。

## 8. 提交版模板门控

完整论文进入 `READY_TO_SUBMIT` 前，至少满足一种情况：

```text
A. template_source = official
   且 official_template_current = true

B. template_source = user
   且 submission_template_verified = true
   且已按当届官方要求完成逐项版式核对
```

若：

```text
template_source = skill_fallback
```

则只能作为工作稿，不允许直接进入 `READY_TO_SUBMIT`。
