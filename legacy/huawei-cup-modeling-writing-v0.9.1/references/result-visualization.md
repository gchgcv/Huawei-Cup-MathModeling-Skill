# 深层参考：结果图表、结构图与图文讨论

本文件负责**图文件本身**的信息表达、语言、可读性和图文解释。正式图文件的版本唯一性、旧图/别名清理与 canonical manifest 由 `references/figure-artifact-management.md` 负责。插入 LaTeX/Word 后的浮动、分页、题注分离、页面裁切和版面空白不属于本文件职责，统一由 `references/latex-pdf-layout-audit.md` 处理。探索性可视化若只是内部分析，可按 `data-preprocessing-visualization` 执行；一旦准备进入论文或答辩材料，则按本文件做正式出图检查。

## 1. 图表职责

- 表格：精确数值、排名、参数和方案对比；
- 折线：时间或连续变化；
- 柱状：离散对象比较；
- 散点/残差：关系、拟合和异常；
- 热力图：矩阵、时空或参数组合；
- 甘特图/网络图/地图：仅在结构信息真实存在时使用；
- 流程图：真实的处理步骤、分支、循环或阶段依赖；
- 结构框图：模块、对象、输入输出或层级关系确实需要视觉表达时使用。

## 2. 禁止“文字装进框里就当图”

论文中不要把一句话、一个线性关系或若干短语简单放进矩形边框，再用箭头串起来作为独立图片。若只是单向、无分支、可用一两句话说清，改为正文；只有真实存在阶段、模块、分支、循环或多对象交互时，才使用流程图或结构框图。

箭头若表示因果，必须有机理、模型假设或证据支撑；只有关联、参数传递或计算顺序时，不写成“因果链”。

## 3. 正式代码出图的语言规则

中文论文中，代码生成图片的主要说明文字默认使用中文，包括坐标轴名称、图例名称、注释、方案名称和类别名称。以下内容可保留标准写法：

- 专有名词、数据集名、算法名、软件名；
- 公认缩写；
- 变量、数学符号、希腊字母；
- 物理量符号和单位；
- 翻译后反而容易产生歧义的少量专业术语。

若论文外部图注已经承担完整标题，代码图内通常不再重复放同义标题，避免与正文图注重复；用户模板或题目明确要求图内标题时除外。

中文字体不得只靠“代码里指定了字体”判断成功。若运行日志出现 missing glyph，或实际渲染出现方框、乱码、负号异常等问题，必须修复。不要无条件硬编码当前环境不存在的字体路径。

## 4. Codex / Agent 正式出图闭环

对于准备进入论文的代码生成图片，不能以“脚本运行成功”或“`savefig` 成功”作为通过依据。必须执行：

```text
运行绘图代码
→ 保存实际图文件
→ 打开或渲染该图文件
→ 按目标论文尺寸检查可读性
→ 修改绘图代码
→ 重新生成
→ 再次打开检查
```

能直接查看图片的 Agent/Codex 环境应检查**实际生成文件**，而不是只读绘图源码推测效果。若当前环境无法打开、渲染或可靠查看图片，应登记 `FIGURE_VISUAL_UNVERIFIED`，不能声称“图片已检查无问题”。

断点续接已有完整论文时，如果最终 PDF 的逐页渲染能够清楚显示该图在实际版面尺寸下的全部内容，可直接把对应 PDF 页面作为图像可读性的视觉证据，不强制为了流程完整再重复打开同一独立图文件。只有发现缺陷、需要修改绘图代码，或 PDF 中无法判断图文件本身问题时，才回到原图与绘图代码。

## 5. 图文件视觉检查

检查重点是信息清晰和论文尺寸下可读，不追求固定配色模板或主观“高级感”。至少确认：

- 刻度数量和数字格式合理，没有相互重叠；
- 坐标轴标签、图例和注释没有遮挡关键曲线、柱体、散点或区域；
- 多条曲线、标记和图例能一一对应；
- 子图、标签、标题和注释没有拥挤到难以阅读；
- 文字、符号和图元没有被裁掉；
- 纵横比例没有把图形明显拉伸、压扁或变形；
- 字体、线宽、点大小与最终图幅匹配；
- 小数位数和科学计数法使用合理，不因过长数字造成刻度拥挤；
- 信息过载时拆图，而不是继续缩小字体和图元；
- 多子图默认最多两列；三维运动状态、机构结构或标注密集的图优先拆分，不能用四列小图换取页数压缩；
- 图中单位、刻度和文字必须在最终论文尺寸下可读，独立原图清晰不能替代 PDF 实际尺寸的可读性证据；
- 中文字体和数学符号均能正常显示。

发现问题时，应回到绘图代码修正，例如调整画布比例、边距、刻度密度、有效位数、图例位置、标注位置、标签旋转、子图布局或拆图。不要只在图片文件上手工遮盖问题而失去可复现性。

如果缺陷已经影响数据读取、曲线辨认或结论判断，登记 `FIGURE_VISUAL_DEFECT` 为 P1；仅有轻微审美问题但不影响信息读取时，可登记为 P2。

## 6. 结果分析不能停在“看图说趋势”

核心图表后的讨论应与其重要性相匹配，通常覆盖主要现象、关键数值、模型或机理解释、对应子问题，以及必要的异常或边界。不要机械写固定五段，也不能只写“由图可知趋势明显”。

模型对比图应明确基准、指标和差异幅度；敏感性图应说明稳定区间、阈值或排序变化；验证图应说明残差、误差、可行性或理论条件是否满足。

## 7. 一致性检查

图表数据必须来自最终结果文件。核对排序、单位、图例、颜色/标记含义、有效位数和正文引用。图后解释不得与结果台账或当前模型版本冲突。
