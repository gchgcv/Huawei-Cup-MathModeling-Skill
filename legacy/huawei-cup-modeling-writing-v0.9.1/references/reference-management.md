# 深层参考：参考文献管理

本文件是参考文献真实性、相关性、来源边界和引用完整性的唯一详细规则源。`paper-writing`、`submission-audit` 与 `quality-gates` 只负责调用或判定，不重复展开本文件细则。

## 1. 适用范围

仅在以下任务中启用：

- 写作或完善正式论文；
- 整理、核验或补充参考文献；
- 生成或维护 BibTeX / 文献列表；
- 做终稿引用审计。

纯读题、建模、编程或局部结果分析任务，不得为了“形式完整”主动扩展成文献检索任务。

## 2. 最低要求

正式论文的参考文献表不得为空，并且至少应有一条被正文实际引用、与当前题目或所用方法直接相关的有效来源。

不设置固定数量目标。文献数量以支撑以下内容为准：

- 题目背景中的必要事实；
- 模型或算法来源；
- 参数、常数、标准或数据定义；
- 与结果解释直接相关的领域知识。

不得为了数量堆砌与论文无关的条目。

## 3. 来源要求

优先使用可核验且与当前任务直接相关的来源，例如：

- 教材、专著或方法原始论文；
- 高质量综述；
- 标准、规范、政府或权威机构资料；
- 数据集、软件、算法的官方说明；
- 与题目背景直接相关的可靠学术或行业来源。

每条最终文献必须同时满足：

1. 来源真实；
2. 书目信息可核验；
3. 与正文存在明确关系；
4. 正文存在实际引用；
5. 没有把未阅读、未核实的条目写成已经使用。

无法核实的作者、题名、年份、期刊、DOI、URL 或出版信息不得凭记忆补全。

## 4. 历年旧题训练的特殊边界

当任务属于历年竞赛题训练、模拟复现或自主建模练习时，以下材料不得作为正式论文参考文献，也不得作为主模型成立的学术依据：

- 官方参考答案或官方解题说明；
- 优秀论文、获奖论文或官方范文；
- 培训机构现成解答；
- 网络上针对同一道题的完整解题帖、代码答案或复现稿。

如果用户明确要求“对照官方答案/优秀论文做复盘”，这些材料可以作为**对照材料**使用，但必须与学术参考文献分离，不能混入正式参考文献表，也不能反向包装成自主建模依据。

检索旧题相关文献时，应优先搜索模型、算法、领域背景和数据来源本身，而不是搜索该赛题的现成答案。

## 5. Agent / Codex 执行规则

Agent 不得从语言模型记忆中直接拼接看似完整的参考文献。执行顺序应为：

```text
确定正文实际需要的依据
→ 查找或读取可靠来源
→ 核验书目信息
→ 确认正文引用位置
→ 写入文献表 / BibTeX
→ 再检查引用键与正文对应
```

若运行环境不能联网，且用户没有提供足以核验的来源：

- 可以保留待补文献占位需求；
- 应登记 `REFERENCE_UNVERIFIED` 或 `REFERENCE_MISSING`；
- 不得生成虚构的作者、题名、期刊或 DOI 来填满文献表。

编辑已有 `.bib` 时优先继承原格式和 cite key；除非发现重复、错误或用户要求，不主动重命名全部引用键。

## 6. 完成检查

终稿至少确认：

- 文献表非空；
- 正文引用与文献表双向对应；
- 没有仅为凑数加入的无关文献；
- 没有未核实却写得像已核实的条目；
- 旧题训练没有把官方答案、范文或现成解答混入正式参考文献。

## 7. 顺序编码与格式统一

当目标竞赛或官方模板采用顺序编码制时，严格按正文首次出现顺序编号：

- 正文第一次引用必须是 `[1]`，后续按首次出现顺序递增；
- 同一处多个引用按编号升序排列，例如 `[5,6]`，不写成 `[6,5]`；
- 文献表顺序、正文引用、BibTeX cite key 和交叉引用必须相互对应；
- 全文只采用一套书目格式。官方模板有明确要求时服从官方模板；没有明确要求时默认采用 GB/T 7714 顺序编码制，并按书籍 `[M]`、期刊 `[J]`、标准 `[S]` 等类型统一著录；
- DOI、URL、作者、年份和出版信息必须留在对应条目内，不能因换页或手工排版形成孤立信息。

首次引用不是 `[1]`、编号顺序倒置或同一列表混用多种格式时，终稿登记
`REFERENCE_ORDER_ERROR` 或 `REFERENCE_FORMAT_INCONSISTENT`，不能只以“文献内容正确”通过格式审核。
