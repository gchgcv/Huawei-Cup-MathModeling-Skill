# Reference Standard

## REF-001 — 文献真实且书目信息可核验

- **Normative Statement:** 最终引用的作者、题名、年份、出版物、DOI、URL 或标准信息必须来自实际核验来源，不得凭记忆补全或编造。
- **Scope:** 参考文献表、BibTeX 和正文来源陈述。
- **Required Exceptions:** 尚未核验的来源只能保持明确待核实状态，不能作为正式文献事实。
- **Relations:** `CLAIM-002`, `TERM-003`。

## REF-002 — 文献与正文存在实际关系

- **Normative Statement:** 正式文献应支撑正文中的背景事实、模型方法、参数标准、数据定义或结果解释，并在正文中实际引用；不得为数量堆砌无关条目。
- **Scope:** 正式参考文献表。
- **Required Exceptions:** 延伸阅读清单若与正式参考文献明确分离，可以不在正文逐条引用。
- **Relations:** `CLAIM-002`, `DEPTH-004`。

## REF-003 — 旧题答案材料不得冒充学术依据

- **Normative Statement:** 历年竞赛题训练中的官方答案、获奖范文、培训机构现成解答和同题完整解题材料不得进入正式学术参考文献，也不得包装为自主模型成立的依据。
- **Scope:** 旧题训练、复现和复盘论文。
- **Required Exceptions:** 用户明确要求复盘时，这些材料可以作为与正式参考文献分离的对照材料。
- **Relations:** `REF-001`, `REF-002`。
## REF-004 — 引用顺序和格式体系统一

- **Normative Statement:** 正文引用、文献表顺序和引用键应相互对应；全文应采用目标模板要求的一套书目格式，不得混用互不兼容的著录体系。
- **Scope:** 正文引用和参考文献表。
- **Required Exceptions:** 官方模板允许分类型文献表时可以使用其规定结构。
- **Relations:** `FMT-001`, `FMT-005`。

## REF-005 — 正式论文文献表不得为空

- **Normative Statement:** 涉及外部背景、方法来源、参数标准或数据定义的正式论文应包含真实、相关且被正文使用的参考文献，不能以未经核验占位符替代。
- **Scope:** 完整或候选终稿论文。
- **Required Exceptions:** 题目及全部方法均完全自包含且不依赖任何外部事实的特殊任务，应明确说明其来源边界。
- **Relations:** `REF-001`, `REF-002`。
